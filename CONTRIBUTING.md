# Contributing

Students should copy `template/` into one new `papers/<team-name>/` folder and
submit that folder in a pull request. See [README.md](README.md) for the exact
commands and paper requirements. The editorial team owns `proceedings/`,
`config/`, `scripts/`, and the workflows. After accepting a paper, an editor
adds its `\subfile{../papers/<team-name>/paper}` line to
`proceedings/papers.tex` in the intended publication order.

Please keep citations complete and figures reproducible. The four-page limit
includes references. A green CI check is required before merging.
